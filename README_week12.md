## 角色1 交付物

### 1. 核心产出
- **误判样本初选表**：`outputs/error_cases.csv`
  - **内容**：包含模型预测错误的 ≥10 条短信原文、真实/预测标签、错误原因分析。
  - **列定义**：
    - `text`：原始短信内容
    - `true_label`：真实标签 (ham/spam)
    - `pred_label`：模型预测标签 (ham/spam)
    - `reason`：错误分类的简要分析（如“正常短信被误判为垃圾：含有URL”、“垃圾短信被漏判：文本过短”）

- **分析日志**：`outputs/logs/error_analysis_log.txt`

### 2. 错误分析小结（可直接用于报告）
本次实验使用逻辑回归模型在20%测试集上进行评估，共抽取到 X 条误判样本（请将X替换为实际数字）。
- **错误类型分布**：
  - **正常短信被误判（False Positive）**：主要因为短信中含有数字串、链接或营销类用语。
  - **垃圾短信被漏判（False Negative）**：常见原因是文本过短，缺乏典型关键词，或伪装成日常对话（如包含“love”、“home”等词）。
- **结论与改进方向**：当前基线模型对短文本和伪装性强的垃圾短信识别能力有限。后续可尝试引入 **N-gram 特征**、**文本长度**等非词频特征来增强模型，减少此类误判。
